# Database

PostgreSQL dialect, managed with Drizzle ORM. Source of truth: `backend/src/db/schema.ts`.
Migrations: `database/migrations/*.sql` (generated by drizzle-kit, applied automatically at
startup and by `npm run db:migrate`; applied migrations are tracked in `drizzle.__drizzle_migrations`).

Two drivers, same SQL:

- **PostgreSQL** (`DATABASE_URL`) — production. Tested in CI against PostgreSQL 17 (not run locally in the original environment).
- **PGlite** (embedded PostgreSQL 18 compiled to WASM) — default when `DATABASE_URL` is empty;
  used by all local tests. Single connection; suited to single-node installs.

All timestamps are `timestamptz`. IDs are UUID v4 (`gen_random_uuid()`), except append-only
tables using `bigserial`.

## Tables

### users

| Column                                | Type                                     | Notes                                           |
| ------------------------------------- | ---------------------------------------- | ----------------------------------------------- |
| id                                    | uuid PK                                  |                                                 |
| email                                 | text                                     | unique on `lower(email)`                        |
| name                                  | text                                     |                                                 |
| password_hash                         | text                                     | argon2id (PHC string)                           |
| role                                  | enum `user_role` (viewer, editor, admin) | default viewer                                  |
| disabled                              | boolean                                  | disabled users cannot sign in; sessions deleted |
| must_change_password                  | boolean                                  | set for admin-created users and resets          |
| failed_login_count                    | int                                      | reset on success; lock at 10                    |
| locked_until                          | timestamptz                              | lockout end                                     |
| last_login_at, created_at, updated_at | timestamptz                              |                                                 |

### sessions

`id` text PK = **SHA-256 of the session token** (token never stored) · `user_id` → users (cascade) ·
`created_at`, `last_seen_at`, `expires_at` (sliding) · `ip`, `user_agent`.
Indexes: `user_id`, `expires_at`.

### api_tokens

`id` uuid PK · `user_id` → users (cascade) · `name` · `token_hash` (SHA-256, unique) · `prefix`
(first 10 chars for display) · `created_at`, `last_used_at`, `expires_at`, `revoked_at`.

### monitors

| Column                                                            | Type                                      | Notes                                                               |
| ----------------------------------------------------------------- | ----------------------------------------- | ------------------------------------------------------------------- |
| id                                                                | uuid PK                                   |                                                                     |
| name                                                              | text                                      |                                                                     |
| kind                                                              | enum `monitor_kind` (http, llm, mcp)      | immutable after creation                                            |
| enabled                                                           | boolean                                   |                                                                     |
| interval_seconds, timeout_ms, failure_threshold, baseline_samples | int                                       | validated at the API                                                |
| drift_enabled                                                     | boolean                                   |                                                                     |
| ignore_paths, tags                                                | text[]                                    | tags stored lower-case                                              |
| config                                                            | jsonb                                     | kind-specific, **non-secret**                                       |
| secrets_enc                                                       | text                                      | AES-256-GCM `v1.<iv>.<tag>.<ciphertext>` of `{ headers?, apiKey? }` |
| status                                                            | enum `monitor_status` (unknown, up, down) |                                                                     |
| consecutive_failures                                              | int                                       |                                                                     |
| last_checked_at, last_duration_ms, last_error                     |                                           | denormalized for the list view                                      |
| next_run_at                                                       | timestamptz                               | scheduler claim key                                                 |
| created_by                                                        | uuid → users (set null)                   |                                                                     |
| created_at, updated_at                                            | timestamptz                               |                                                                     |

Indexes: partial `monitors_due_idx (next_run_at) WHERE enabled`, `monitors_status_idx`.

### baselines

`monitor_id` uuid PK → monitors (cascade) · `shape` jsonb (`{ samples, paths: { "<path>": { types[], count, emptyArray? } }, truncated? }`) ·
`signature` jsonb (`{ key: { value, severity, label } }`) · `locked_at` (null while learning) · `updated_at`.

### check_results

`id` bigserial PK · `monitor_id` → monitors (cascade) · `started_at` · `duration_ms` · `ok` ·
`status_code` · `error_code` · `message` · `assertions` jsonb `[{name, ok, message}]` · `meta` jsonb ·
`response_excerpt` (≤ 2 KB, secrets redacted, **failed checks only**).
Indexes: `(monitor_id, started_at desc)`, `(started_at)` for retention.

### incidents

`id` · `monitor_id` (cascade) · `opened_at` · `resolved_at` · `cause` · `last_error` · `failure_count`.
Unique partial index `incidents_one_open_per_monitor (monitor_id) WHERE resolved_at IS NULL` —
at most one open incident per monitor, enforced by the database.

### drift_events

`id` · `monitor_id` (cascade) · `detected_at` · `last_seen_at` · `occurrences` · `severity` enum
(breaking, warning, info) · `fingerprint` (SHA-256 of the canonical change set) · `changes` jsonb ·
`observed_shape`, `observed_signature` jsonb (used when accepting) · `status` enum (open, accepted,
dismissed) · `decided_by` → users (set null) · `decided_at`.
Indexes: `(monitor_id, detected_at desc)`, `(status)`, `(monitor_id, fingerprint)`.

### notification_channels

`id` · `name` · `kind` enum (webhook, slack) · `enabled` · `events` text[] · `config_enc`
(encrypted `{ url, secret? }`) · `target` (URL host, for display) · timestamps.

### notification_deliveries (outbox)

`id` · `channel_id` (cascade) · `event_type` · `payload` jsonb · `status` enum (pending, sent, failed) ·
`attempts` · `next_attempt_at` · `last_error` · `response_status` · `created_at` · `sent_at`.
Partial index `deliveries_pending_idx (next_attempt_at) WHERE status = 'pending'`.

### audit_log

`id` bigserial · `user_id` (set null) · `action` · `target_type` · `target_id` · `details` jsonb
(never secret values) · `ip` · `created_at`. Index `created_at desc`.

## Relationships

```
users 1─* sessions, api_tokens            (cascade)
users 1─* monitors.created_by, drift_events.decided_by, audit_log.user_id   (set null)
monitors 1─1 baselines; 1─* check_results, incidents, drift_events            (cascade)
notification_channels 1─* notification_deliveries                             (cascade)
```

## Concurrency patterns

- Scheduler claim: `UPDATE monitors SET next_run_at = now() + interval … WHERE id IN (SELECT … FOR UPDATE SKIP LOCKED LIMIT n) RETURNING id`.
- Outbox claim: same pattern on `notification_deliveries`.
- Recording a check runs in one transaction with `SELECT … FOR UPDATE` on the monitor row and baseline.
- First-admin setup uses `pg_advisory_xact_lock`.

## Retention

Hourly job (`jobs/jobs.ts#pruneOldData`): deletes `check_results` and non-pending
`notification_deliveries` older than `RETENTION_DAYS` (default 30), and expired `sessions`.
Incidents, drift events, baselines and the audit log are kept indefinitely (no pruning yet — see ROADMAP).

## Seeds

`database/seeds/demo.ts` creates demo monitors (idempotent by name). No seed data is loaded
automatically.

## Backups

Standard PostgreSQL tooling (`pg_dump`). For PGlite, stop the process and copy `PGLITE_DATA_DIR`.
Back up `ENCRYPTION_KEY` separately — encrypted columns are useless without it.
